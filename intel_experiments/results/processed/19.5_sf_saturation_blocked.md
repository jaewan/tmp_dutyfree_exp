# Phase 19.5 SF Saturation Control Blocked

The 8592+ Phase 18-equivalent SF saturation control requires
`bench/aggressor/forced_turnover`, which disables hardware prefetchers through
MSR 0x1A4 before running the 4 MB/core turnover workload.

Attempted command:

```bash
numactl --membind=0 --cpunodebind=0 -- \
  ./bench/aggressor/forced_turnover --cpu 1 --node 0 \
  --region-bytes 4194304 --seed 1
```

Observed:

```text
/dev/cpu/1/msr: Operation not permitted
msr_pf_disable: read MSR 0x1A4 failed on cpu1
forced_turnover: WARNING: prefetcher disable failed on cpu1
...
pf_disabled=0
```

This is not the Phase 18-equivalent workload because prefetchers remained on.
No SF saturation data was accepted.

`env/setup.sh` has been updated so the next sudo setup run grants
`cap_sys_rawio=ep` to `bench/aggressor/forced_turnover`, matching
`stream_wb_nopf` and `pointer_chase`.
