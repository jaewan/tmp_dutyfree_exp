# Phase 19.0 Amended CXL Latency Validation

## Verdict

**HALT.** The amended 512 MB CXL pointer-chase validation failed because
median latency was below the pre-registered 300 ns floor.

## Gate Result

| Case | WSS | n | Median ns | IQR ns | Min ns | Max ns | NUMA huge N2 |
|------|-----|---|-----------|--------|--------|--------|--------------|
| CXL_512MB_gate | 512 MB | 10 | 168.93 | 23.88 | 161.96 | 229.14 | 10/10 |
| CXL_64MB_record | 64 MB | 10 | 40.52 | 0.03 | 40.48 | 40.66 | 10/10 |

Required amended gate: 512 MB median in [300 ns, 600 ns].

## Interpretation

The 512 MB working set is 8.5x the 60 MB LLC capacity, so this run should
have forced CXL-bound pointer-chase misses. `/proc/PID/numa_maps` confirmed
node-2 hugepage residency in every trial (`N2=256`, 2 MB hugepages), but
latency still measured 168.93 ns median. This triggers the resume-specific
halt condition:

```text
Amended 19.0 validation returns <300 ns
```

The 64 MB record-only run reproduced the LLC-dominated result at ~40.5 ns.
